# LEVEL NINE GYM — Telegram-бот «Облік працівників»

Звичайний Telegram-бот без жодних AI-сервісів. Облік приходу/виходу, зарплата
100 грн/год до хвилини, аванси й виплати, звіти каси та фото-звіти, проблеми
з фото/відео, база інструкцій (Level Nine, Instasport), панель власника,
повідомлення власнику про все, щоденний підсумок, нічна резервна копія.
Працює 24/7 на комп'ютері зала, стартує з Windows і сам оновлюється з GitHub.

Репозиторій: https://github.com/FallenGodN/levelnine-bot

---

## 1. Правила, які закладено (ТЗ від 30.09.2026)

- **Юлія та Ірина — 100 грн/год.** Зарплата рахується до хвилини за фактичним
  часом між «Прийшла» і «Пішла». Відкрита зміна рахується «на зараз».
- **Власник — без зарплати**, у підсумки не входить. Адміністратори теж.
- **Автозакриття о 22:20.** Хто забув натиснути «Пішла», тому бот закриває
  зміну о 22:20 і пише власнику. О 21:50 працівник отримує нагадування.
- **Аванси та виплати** додає адміністратор з підтвердженням; повторний тап
  нічого не дублює. Залишок = нараховано − аванси − виплати.
- **Звіт каси**: працівник фотографує касу / звіт і надсилає. Зберігається
  дата, час, працівник, файл. **Фото-звіт** — будь-яке інше фото для власника.
  **Проблема** — опис + фото/відео, власник отримує негайно; у списку
  проблем адміністратор ставить «✅ Вирішено».
- **Допомога** — розділи Level Nine, Instasport (і будь-які інші) з
  інструкціями: текст + скріншоти/відео. Додає й редагує адміністратор прямо
  з бота. Бот нічого не вносить в Instasport, лише підказує, як.
- **Власнику приходить усе**: приходи, виходи, автозакриття, звіти каси,
  фото-звіти, проблеми, аванси й виплати, зміни ставок, тривоги.
- **База** — SQLite у `data/`, щодня о 03:30 файл бази летить власнику в
  Telegram, на диску зберігаються 14 останніх копій.

## 2. Встановлення на комп'ютер зала (Windows)

1. Відкрийте `cmd` (Win+R → `cmd`) і вставте:

   ```
   curl -L -o %TEMP%\install.ps1 https://raw.githubusercontent.com/FallenGodN/levelnine-bot/main/install.ps1 && powershell -NoProfile -ExecutionPolicy Bypass -File %TEMP%\install.ps1
   ```

   Інсталятор сам ставить Node.js і Git з офіційних сайтів, завантажує бота
   в `C:\levelnine-bot`, питає токен бота (з @BotFather) і Telegram ID
   власника (бот показує його на /start), вмикає автозапуск.
2. Якщо Windows 11 блокує запуск (Smart App Control) — вимкніть його:
   Безпека Windows → Керування програмами та браузером → Smart App Control →
   Вимк.
3. Комп'ютер не повинен засинати: Параметри → Система → Живлення → сон
   «Ніколи».

Зупинити бота: `C:\levelnine-bot\tools\stop-bot.cmd`. Лог: `bot.log` там же.
Один токен = один запущений бот.

Додаткові адміністратори без зарплати задаються в `.env` рядком
`EXTRA_ADMINS=947529523:Максим,8951109005:Рецепція` (ID:ім'я через кому).
Змінили `.env` — перезапустіть: `stop-bot.cmd`, потім `wscript //B
"%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\LevelNineBot.vbs"`.

## 3. Як користуватись

**Працівник** (кнопки внизу екрана):

| Кнопка | Що робить |
|---|---|
| 🟢 Прийшла / 🔴 Пішла | відмітка приходу і виходу; після «Пішла» бот показує години й суму |
| 📊 Моя статистика | години за місяць, усі зміни |
| 💰 Моя зарплата | нараховано, аванси, виплати, залишок |
| 💵 Звіт каси | сфотографувати касу і надіслати |
| 📷 Фото-звіт | будь-яке фото/відео для власника |
| ⚠️ Проблема | опис → фото/відео → власник отримує одразу |
| 🆘 Допомога | інструкції по Level Nine та Instasport |

Просто надіслане боту фото стає фото-звітом; кнопками під ним можна
перекласифікувати його в звіт каси або проблему.

**Адміністратор / власник** додатково:

| Кнопка | Що робить |
|---|---|
| 👑 Панель | хто працює зараз (години, сума), сьогодні, місяць по кожному, звіти, відкриті проблеми |
| 🟢 Хто працює | відкриті зміни |
| 👥 Працівники | ставки, код прив'язки, Telegram ID, адмін, деактивація, ➕ додати (за годину / день / місяць / без зарплати) |
| 📅 Історія змін | останні 30 |
| 💰 Зарплата | по працівнику, по місяцях, історія операцій |
| ➕ Аванс · 💸 Виплата | кому → сума → коментар → ✅ Підтвердити |
| 📝 Виправити зміну | початок / кінець / закрити зараз / видалити / додати |
| 📁 Звіти | каса, фото, проблеми — сьогодні / останні / за датою; ✅ Вирішено |
| 📊 Місячний звіт | години й суми по всіх, 📥 Excel (підсумок, зміни, аванси, звіти) |
| 🚨 ТЕРМІНОВО | негайно власнику та в адмін-групу; бот каже, куди доставлено |
| ⚙️ Налаштування | версія, час підсумку, копія зараз, тест у групу, 🔄 оновити |

Ставки змінює лише власник. Команди: `/menu`, `/id`, `/chatid`, `/version`, `/update`.

**Адмін-група.** Створіть групу, додайте бота, напишіть у групі `/chatid`,
натисніть кнопку під відповіддю. Без групи все приходить власнику особисто.

**Прив'язка працівника.** 👥 Працівники → ім'я → 🔗 Код прив'язки → передайте
6 цифр працівнику; він відкриває бота, Start, надсилає код. Один раз.

## 4. Що бот робить сам

- щохвилини перевіряє зміни: о 22:20 закриває забуті, о 21:50 нагадує;
- через годину після відкриття залу пише, хто не відмітився (вимикається в ⚙️);
- о 22:30 підсумок дня (час змінюється в ⚙️): хто прийшов, години й суми,
  автозакриття, звіти, проблеми, попередження;
- о 03:30 резервна копія бази власнику;
- кожні 10 хвилин перевіряє GitHub і сам оновлюється.

## 5. Витрати

Нуль. Хостинг — комп'ютер зала, Telegram безкоштовний, AI-сервісів немає.
Варіант у хмарі (Railway, 5 $/міс) описаний у `Dockerfile` / `railway.json`,
якщо колись знадобиться незалежність від комп'ютера зала.

## Для розробника

```
npm install
cp .env.example .env      # BOT_TOKEN, OWNER_TELEGRAM_ID
npm test                  # 29 тестів: погодинна зарплата, автозакриття 22:20, потоки бота, звіти, допомога, планувальник, оновлення
npm start
```

`src/`: `config.js` (змінні, ставка, графік, 22:20), `time.js` (Київ, гроші,
години), `db.js` (SQLite, сід, міграції), `employees.js`, `shifts.js`,
`payroll.js` (до хвилини), `reports.js` (каса / фото / проблеми), `help.js`
(база інструкцій), `notify.js` (група + власник), `scheduler.js`,
`updater.js`, `export.js` (Excel), `bot.js` (меню, діалоги), `index.js`.
Тести ганяють бота через `bot.handleUpdate` зі стабом Telegram API.
