# LEVEL NINE GYM — Telegram-бот «Облік працівників»

Бот для @levelninegym_bot: відмітки приходу/виходу, зарплата (1 400 грн/день,
12 000 грн/міс, власник 0), аванси й виплати з підтвердженням, звіти каси
(фото / PDF / Excel / текст), адмін-група, тривожна кнопка, AI-помічник
(OpenAI, лише читання), щоденний підсумок, автозакриття змін через 10 год,
щоденна резервна копія бази власнику в Telegram. Працює 24/7 на сервері —
телефон і браузер не потрібні.

---

## 0. Найшвидший шлях: комп'ютер зала (безкоштовно)

Бот може жити на будь-якому Windows-комп'ютері, який не вимикають.

1. Завантажте `install.cmd` з GitHub (кнопка *Download* на файлі) і запустіть
   подвійним кліком. Він сам поставить Node.js і Git, скачає бота в
   `C:\levelnine-bot`, спитає токен бота та Telegram ID власника і ввімкне
   автозапуск при вході в Windows.
2. Все. Бот стартує сам після кожного ввімкнення, перезапускається після
   збою і **кожні 10 хвилин сам підтягує оновлення з GitHub**. Кнопка
   ⚙️ Налаштування → 🔄 Оновити бота робить це негайно; там же видно версію.
3. Зупинити: `C:\levelnine-bot	ools\stop-bot.cmd`. Лог: `bot.log` у тій
   же папці.

Важливо: один токен = один запущений бот. Якщо бот уже працює на іншому
комп'ютері, спершу зупиніть його там.

Що бот робить сам, окрім автозакриття й підсумку: через годину після
відкриття залу пише в групу, хто ще не відмітився (вимикається в ⚙️), і за
годину до автозакриття нагадує працівнику особисто натиснути «Пішла».
📊 Місячний звіт має кнопку 📥 Excel: підсумок, усі зміни, аванси й виплати,
звіти каси одним файлом.

## 1. Що потрібно від власника (варіант із Railway, 24/7 у хмарі) (по одному кроку)

1. **Токен бота.** У Telegram відкрийте @BotFather → `/mybots` →
   @levelninegym_bot → *API Token*. Якщо старий бот ще десь запущений,
   натисніть *Revoke current token* — старий проєкт зупиниться, а два
   сервери з одним токеном заважали б один одному. Токен нікому не
   надсилайте, він вводиться лише в Railway (крок 3).
2. **Ключ OpenAI.** platform.openai.com → *API keys* → *Create new secret
   key*. Там же в *Billing → Limits* поставте місячний ліміт, наприклад
   10 $. Ключ теж іде лише в Railway.
3. **Railway.** Зареєструйтесь на railway.com (план Hobby, 5 $/міс,
   картка потрібна). Далі: *New Project → Deploy from GitHub repo* → цей
   репозиторій. У сервісі відкрийте **Variables** і додайте:

   | Змінна | Значення |
   |---|---|
   | `BOT_TOKEN` | токен із кроку 1 |
   | `OPENAI_API_KEY` | ключ із кроку 2 |
   | `OWNER_TELEGRAM_ID` | ваш ID (крок 4) |
   | `DATA_DIR` | `/data` |

   Потім **Settings → Volumes → Add Volume**, mount path `/data`. Без
   цього база зникне після перезапуску. Натисніть *Deploy*.
4. **Ваш Telegram ID.** Відкрийте бота, натисніть Start — він покаже
   `Ваш Telegram ID: 123456789`. Впишіть число в `OWNER_TELEGRAM_ID`
   (крок 3) і зробіть *Redeploy*. Після цього бот вітає вас як власника й
   показує меню адміністратора.
5. **Адмін-група.** Створіть групу *LEVEL NINE | ADMIN*, додайте туди бота
   (як адміністратора, щоб він бачив команди), напишіть у групі `/chatid`
   і натисніть кнопку **«✅ Зробити цю групу адмін-чатом»**. Все — ID у
   Secrets вписувати не обов'язково (але можна: `ADMIN_CHAT_ID`).
6. **Працівники.** Меню → 👥 Працівники → Юлія → 🔗 Код прив'язки. Бот
   дасть 6-значний код. Перешліть його Юлії: вона відкриває бота,
   натискає Start і надсилає код. Те саме для Ірини та прибиральника.

## 2. Як користуватись з iPhone

**Працівник** бачить чотири великі кнопки внизу екрана:

- 🟢 **Прийшла / Прийшов** — натиснути вранці. Повторне натискання нову
  зміну не створює.
- 🔴 **Пішла / Пішов** — після роботи. Якщо забули — бот сам закриє зміну
  через 10 год і напише в адмін-групу «автоматично закрито». На зарплату
  це не впливає: за день завжди рівно 1 400 грн, скільки б не було годин
  чи відміток.
- 📊 **Моя статистика** — зміни цього місяця.
- 💰 **Моя зарплата** — нараховано, аванси, виплати, залишок.
- 📸 **Надіслати звіт каси** — або просто надішліть боту фото/файл; підпис
  до фото стає коментарем.
- 🤖 **AI-помічник** — запитайте своїми словами. Працівник бачить лише
  свої дані.

**Адміністратор** має 12 кнопок меню (двома колонками):

| Кнопка | Що робить |
|---|---|
| 👥 Працівники | ставки, код прив'язки, ввести Telegram ID, зробити адміном, деактивувати, ➕ додати |
| 🟢 Хто працює | відкриті зміни зараз |
| 📅 Історія змін | останні 30 змін, усіх або одного |
| 💰 Зарплата | по працівнику: нараховано / аванси / виплати / залишок, ◀️ ▶️ по місяцях, історія операцій |
| ➕ Додати аванс / 💸 Додати виплату | кому → сума → коментар → **✅ Підтвердити**. Повторне натискання нічого не додає. Запис іде в адмін-групу |
| 📝 Виправити зміну | працівник → зміна → початок / кінець / закрити зараз / видалити, або ➕ додати вручну |
| 📸 Звіт каси | надіслати фото / PDF / Excel / текст |
| 📁 Переглянути звіти | сьогодні · останні 10 · за датою; під кожним звітом кнопка 🤖 Аналізувати |
| 📊 Місячний звіт | усі працівники (без власника), разом, кількість звітів каси |
| 🤖 AI-помічник | питання про зміни, зарплату, звіти; складання повідомлень. Нічого не змінює |
| 🚨 ТЕРМІНОВО | підтвердження → текст → негайно власнику та в групу. Бот пише «доставлено» лише після підтвердження Telegram |
| ⚙️ Налаштування | час щоденного підсумку, підсумок зараз, резервна копія зараз, тест у групу, витрати AI |

Кнопка **❌ Скасувати** перериває будь-який діалог. Команди `/menu`,
`/id`, `/chatid` — додатково.

## 3. Що бот робить сам

- **Автозакриття** — щохвилини перевіряє відкриті зміни; старші за 10 год
  закриває часом «початок + 10 год» і повідомляє групу.
- **Щоденний підсумок** о 22:30 (змінюється в ⚙️): хто прийшов, хто не
  відмітився, хто працює, автозакриті зміни, нараховано за день, звіти
  каси, попередження (відмітки поза графіком, неприв'язані працівники).
  Надсилається один раз на день — після перезапуску дубля не буде.
- **Резервна копія** о 03:30 — файл бази власнику в особисті
  повідомлення. Файли звітів і копії лежать на Volume `/data`.
- **Графік** Пн–Пт 08:00–22:00, Сб 09:00–18:00, Нд 09:00–16:00: відмітка
  поза ним зберігається як є, група отримує «⚠️ Поза графіком».

## 4. Витрати

| Що | Скільки |
|---|---|
| Railway Hobby | 5 $/міс (включає 5 $ ресурсів; бот споживає ~1–2 $) |
| OpenAI, модель gpt-4.1-mini | 0,40 $ за 1 млн вхідних і 1,60 $ за 1 млн вихідних токенів. Кілька сотень запитів на місяць ≈ 1–3 $. У боті стоїть стоп-ліміт 10 $/міс (`OPENAI_MONTHLY_LIMIT_USD`), поставте такий самий у кабінеті OpenAI |
| Telegram | безкоштовно |

## 5. Обмеження, про які варто знати

- Bot API дозволяє боту завантажувати файли до **20 МБ**. Більший файл
  зберігається як посилання в Telegram, але AI його не прочитає.
- AI читає Excel, PDF з текстом, текст і фото (через розпізнавання
  зображень). Скан без тексту або розмите фото → бот чесно каже, що не
  може прочитати, а не вигадує суми.
- Прибиральнику нараховується **повна** ставка 12 000 грн за кожен місяць
  від місяця найму. Пропорційне нарахування за неповний місяць не
  ведеться — якщо потрібно, це узгоджується окремо.
- Ставки змінює лише власник (кнопка 💵 у картці працівника, з
  підтвердженням). Адміністратори ставки не змінюють.

## Для розробника

```
npm install
cp .env.example .env      # впишіть BOT_TOKEN (тестовий бот від @BotFather)
npm test                  # 33 тести: правила зарплати, автозакриття, потоки бота, AI, збереження
npm start                 # long polling; Ctrl+C зупиняє
```

Структура `src/`: `config.js` (змінні оточення, ставки, графік), `time.js`
(київський час), `db.js` (SQLite, схема, сід), `employees.js`, `shifts.js`,
`payroll.js`, `reports.js` (домен), `extract.js` (Excel/PDF → текст),
`ai.js` (OpenAI + інструменти лише для читання + ліміт витрат),
`notify.js` (група / власник), `scheduler.js` (автозакриття, підсумок,
копія, нагадування, автооновлення), `updater.js` (git pull + npm install),
`export.js` (Excel місяця), `bot.js` (меню, діалоги, кнопки), `index.js` (запуск).

Тести ганяють бота через `bot.handleUpdate` зі стабом Telegram API та
фальшивим OpenAI, тому токени для `npm test` не потрібні.
